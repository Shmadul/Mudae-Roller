# Mudae-Roller
Discord Bot Used to Automate Rolls For the Mudae Discord Bot
# Dedpendencies
npm install discord.js
# Setup
Mudae Ignores Normal Bot User tokens, So Use a Token from a real Discord User account and place insode
client.login('');

To run the bot use
node roller.js

Can be ran in multiple instances with
node roller.js & node roller2.js & roller3.js, etc......
